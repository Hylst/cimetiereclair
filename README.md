# Cimetière Clair : Nuit Blanche

**Tiens ta torche allumée**

Joue en ligne sur : [https://games.hylst.fr/cimetiereclair/](https://games.hylst.fr/cimetiereclair/)

## Description
Un roguelite de survie en arène fermée où ton halo de lumière repousse les spectres et zombis. Collecte des orbes, choisis tes améliorations magiques et tiens le plus longtemps possible.

## Controles
| Contrôle | Action |
|---|---|
| ZQSD / Flèches | Déplacement du mage |
| Souris / Curseur | Orientation du faisceau lumineux |
| Tactile | Joystick virtuel relatif |

## Developpement
```bash
# Installer les dependances
npm install

# Lancer le serveur local
npm run dev

# Compiler pour la production (build single-file)
npm run build
```
